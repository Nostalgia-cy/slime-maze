# 编码约定

运行代码保存在 `src/`，检查、实验和构建入口保存在 `scripts/`。`dist/` 由构建脚本生成，修改程序时应先编辑源码，再执行 `npm run build`。

- 使用 UTF-8、LF 换行、两个空格缩进、双引号及分号；编辑器配置见项目根目录的 `.editorconfig`。
- 局部变量、函数和方法使用 camelCase，类使用 PascalCase。不会重新赋值的局部变量使用 `const`，循环计数和累计值使用 `let`。
- 一条声明只定义一个局部变量，循环和条件分支使用花括号。公式过长时按运算层次换行，保留原来的括号和求值顺序。
- 一般变量使用含义明确的名称，如 `restLength`、`relativeSpeed`、`previousGradient`。公式中的 `x/y`、`u/v`、`i/j` 等常用记号可以保留。
- 注释说明算法原因、单位和求解顺序。粒子公开字段 `x/y`、`ox/oy`、`rx/ry` 与绘制及实验共同使用，分别表示当前位置、上一位置和静止偏移；`links` 中每项为 `[i, j, restLength]`。
- 物理更新、碰撞、关卡、外观绑定、FFD 和界面分别放在对应模块。`Slime.step` 内保持已有求解顺序，实验和页面调用同一份实现。

`npm test` 先检查运行模块和脚本的语法，再运行数值与交互回归。检查关卡与长时间拖拽还可执行 `node scripts/route.js`、`node scripts/check-stress.js`。

`scripts/fixtures/` 中的文件是历史实验对照，保留原样，不作为当前运行代码的排版示例。数值算法或核心源码修改后，应重新运行对应实验，保持原始数据与源码 SHA256 一致。

# 代码导读

## 运行入口

`src/index.html` 是界面模板，`scripts/build.js` 将共用模块和交互代码内联为 `dist/史莱姆穿迷宫.html`。最终页面不读取外部脚本、图片或网络资源。开发、检查和离线页面使用相同的物理代码。

## 一步软体模拟

`src/physics.js` 的 `Slime.step` 使用固定 1/120 秒步长。粒子的 `x/y` 是当前位置，`ox/oy` 是上一位置，`rx/ry` 是相对于初始质心的静止坐标。64个等质量粒子构成闭合轮廓；每个粒子连接后续第1和第8个粒子。

1. 弹簧模式先计算沿连接方向的弹力与相对速度阻尼，约束模式在后续迭代中投影距离。
2. 由位置差估计隐式速度，衰减95%的整体角位移分量，再施加原有阻尼、位移限幅并预测新位置；预测后作一次轻缓的朝向校正。
3. 主迭代中依次执行结构约束、轮廓局部稳定化、面积投影和可选的全局形状恢复。
4. 将鼠标引导平移分摊到迭代中，再处理障碍和边框接触。
5. 最后交替执行轮廓、面积与接触处理，并以接触投影收尾。

`regularizeContour` 依次处理曲率平滑、过短边和过大转角；转角修正的单次位移受相邻短边长度限制。`projectArea` 使用有向面积梯度。`fit` 拟合平移与二维旋转，供全局恢复、朝向稳定和形变误差计算使用。

`rotationDamping` 从粒子相对质心的位置和隐式位移估计整体角位移，移除其中95%，保留平移与非刚性速度分量。`stabilizeOrientation` 在每个子步的位置预测后执行一次：角度超出±15°目标区间时，以超差的1%作为反向旋转量，最多0.002 rad，绕质心作小幅刚性旋转。单独这一步保持面积、连接长度和局部应变不变；随后执行完整结构及接触求解，因此最终角度可能超出目标区间。两项均独立于全局恢复开关，是角色动作设计，不是角动量守恒或摩擦滚动模型。`check-upright.js` 覆盖30秒持续右拉的16组条件，并验证最后10秒的持续顶墙角度趋于稳定；只禁用这两项可复现旧版转圈。

`src/collision.js` 同时检查粒子和轮廓线段。`segmentInterior` 裁剪线段与矩形内部的交集，`resolve` 将内部点推出障碍，并把线段中间接触修正分配给两个端点。它是离散迭代接触处理，没有实现连续碰撞检测或完整自碰撞。

## 五官和身体如何一起变形

`src/skin.js` 在静止轮廓上为每个五官、高光和气泡采样点计算平均值坐标（mean value coordinates）。权重只计算一次；绘制时用当前64个轮廓点的加权位置得到细节位置。因此整体平移、旋转、挤压以及局部轮廓变化都会传递给细节，不修改物理粒子。

这是内部图案的几何绑定，不增加材料约束，也不构成自交修复。`scripts/check-skin.js` 检查静止重建、仿射精确性、局部变化和两种模型持续挤压下的有限数值。

## FFD与交互

`src/ffd.js` 使用16个控制点进行双三次 Bernstein 映射。轮廓和五官调用相同映射；关键姿态动画驱动控制网格。Jacobian 的21×21网格采样用于折叠提示，不证明全域无折叠。界面在控制点或动画姿态改变时才重算该诊断。

`src/ui.js` 管理拖拽、模式切换、固定步长累积、绘制、顺序通关和录制。切换软体模型只修改 `sim.solver`，不重建粒子。暂停、通关与关卡初始化分别处理；录制停止期间禁用重复点击，旧录制的延迟事件不能重置新录制状态。

## 性能与实验边界

打开“观察细节”并勾选调试网格后，显示最近约1秒的 rAF 帧率、帧间隔 P95 和平均求解耗时。帧率来自浏览器实际回调间隔；求解计时包含步进与路线驱动，不包含绘制。后台或超过250毫秒的中断会重置统计，短时间统计不代表长期性能。调试网格本身也增加绘制开销。

现有深度实验记录了 `physics.js`、`collision.js`、`scene.js` 的原始源码指纹。新增朝向稳定后已重新运行基础对比和120组深度条件，记录当前源码指纹；`study-summary.js` 与报告准备脚本严格核对当前指纹。浏览器帧率与编码能力必须在实际运行环境中测量，模拟事件检查不能替代它们。
